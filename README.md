# 🧮Modern calculator with CustomTkinter

The [CustomTkinter library](https://github.com/TomSchimansky/CustomTkinter) is a powerful Python tool designed to elevate the aesthetics of Tkinter applications. It provides modern, sleek, and visually appealing components, transforming traditional Tkinter interfaces into user-friendly and professional designs.

## How to use
1. **Prerequisites:** Make sure you have Python installed on your machine. You will also need the CustomTkinter library. Install it with the following command: ```pip install customtkinter ```

2. **Execution:** Navigate to the project directory and run the main script: ```python main.py ```
